# 按实际机制选择的深入分支

目录：分类；检索/RAG；Transformer；生成/扩散；Agent；多模态；强化学习。只读相关标题，可以组合；类型名不能代替核验实际机制。

## 分类与预测

原始样本 → 特征 → 分类头 logits → 概率/分数 → 决策 → 标签。明确标签空间、单/多标签、预测单位、损失/class weights；区分 sigmoid 独立概率与 softmax 互斥分布。解释阈值/argmax、校准、类别不平衡和阈值选择集。回归解释目标单位、输出约束、损失和反归一化。缺失信息标未知。

## 检索与 RAG

拆开离线索引和在线查询。核查记录字段、来源/划分、切分单位、更新方式、query 构造、document/caption 表示、Embedding 模型/版本/维度/冻结状态。

核对归一化、相似度/距离公式、候选集合、排序方向、Top-K 与过滤/重排顺序、K 值及依据、返回字段、给生成器的内容。没有公式不默认余弦，没有格式不默认 JSON。教学分数必须标假设。

说明检索记录怎样作为条件/示例；检查索引含测试标注或重复内容的风险。分开检索 Top-K、R-precision 等指标排名和性能名次。

## Transformer 与神经网络

给张量各轴、token/位置/条件来源、投影和层间表示。需要时以 Q/K/V 与 softmax(QKᵀ/√d)V 教学解释标准 attention，但不能擅定作者 heads、mask、norm、cross-attention、位置编码。

说明 attention 在任务中的信息依赖与作用，输出头从何表示预测何变量，哪些参数训练。decoder 架构名不等于自回归执行方式。

## 生成、解码与扩散

先确定自回归、并行、扩散或其他方式，列每步预测变量、条件、更新、输出转换、终止、采样/阈值/约束。重建 decoder 不自动等于逐 token 自回归。

扩散区分数据/潜空间、前向加噪分布、噪声日程、时间步、noise/x₀/velocity 目标、损失、反向更新、采样器/步数/guidance。扩散步与序列帧轴分开。未报告采样器或日程不拿常见设置代填。

## Agent 与决策系统

观察 → 状态/记忆 → 可选动作/工具接口 → 策略/规划 → 环境结果 → 反馈 → 状态更新/终止。说明可见性、工具参数/返回对象、计划与实际轨迹、失败重试/预算规则。LLM 提示链或符号规划不自动证明存在 RL、可执行工具或自主 Agent。

## 多模态与表示学习

逐模态给原始结构、采样/分词、表示、时空粒度、对齐/融合位置、mask、缺失模态与输出空间。对比学习解释正负样本、batch、温度、相似度、损失和训练/推理模态差异。对齐向量不等于可逆编码。

## 强化学习

明确 MDP/POMDP 状态/观察/动作/转移/奖励/终止/折扣/轨迹来源；解释策略、价值/Q 输入输出与优化，on/off-policy、探索、回放、优势/bootstrap 的实际使用。环境反馈、监督标签和偏好奖励分开；训练回报不等于评估成功。缺失奖励或终止规则须说明理解限制。
